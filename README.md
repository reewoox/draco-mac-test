# Draco — tests Mac

Tests automatiques de la version Mac du launcher Draco (serveur privé Dofus Retro), sur les Mac de GitHub Actions.

- **Actions → Draco Mac → Run workflow** : `mode` = `flash` (Flash Player 32 d'Adobe + client du jeu seuls) ou `launcher` (Draco.app complet : connexion, téléchargement du jeu, JOUER, connexion automatique).
- Les captures d'écran et journaux sont dans les artefacts de chaque exécution.
- Le compte de test est dans les secrets du dépôt (`DRACO_EMAIL`, `DRACO_PASSWORD`).

Serveur privé non officiel. Dofus est une marque d'Ankama Games.
